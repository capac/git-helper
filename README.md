# Git commands using natural language

The aim of htis project is to create a Streamlit web app interface where one can use natural language to retrieve the proper git command for a particular situation. It makes use of the HTML version of the [Pro Git book](https://github.com/progit/progit2/releases/download/2.1.450/progit.html) and of the [Pro Git manual]() which both derive from the [Pro Git website](https://github.com/progit/progit2).

It makes use of Streamlit, Qdrant, BeautifulSoup, OpenAI, NumPy and Python.
